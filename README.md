# ระบบรายงานบันทึกการเข้าสอนประจำวัน (สำหรับครูผู้สอน)
**วิทยาลัยเทคโนโลยีศรีราชา (Read-Only 100%)**

เว็บแอปพลิเคชันสำหรับให้ครูผู้สอนสามารถเข้าสู่ระบบเพื่อเรียกดู สรุปสถิติ พิมพ์รายงาน และดาวน์โหลดไฟล์ Excel บันทึกการเข้าสอนประจำวัน **เฉพาะวิชาและห้องเรียนที่ตนเองสอนเท่านั้น**

---

### คุณสมบัติหลัก (Key Features)

1. **ความปลอดภัยระดับสูงสุด (Strictly Read-Only 100%):**
   - คำสั่งทุกคำสั่งในระบบใช้คำสั่ง `SELECT` เท่านั้น
   - มีระบบ Guard สกัดกั้นคำสั่ง `INSERT`, `UPDATE`, `DELETE`, `DROP`, `ALTER` หรือคำสั่งแก้ไขข้อมูลทุกชนิดโดยเด็ดขาด
   - ใช้ `SET TRANSACTION ISOLATION LEVEL READ UNCOMMITTED;` เพื่อไม่ให้เกิดการ Lock ตารางฐานข้อมูลการทำงานจริง
2. **จำกัดสิทธิ์เฉพาะครูแต่ละท่าน (Teacher-Scoped Access):**
   - ครูเข้าสู่ระบบด้วย Username / Password เดิมของระบบ MisSchool
   - ระบบจะผูก `TeacherNo` กับ Session อย่างปลอดภัย ครูจะมองเห็นเฉพาะวิชาและห้องเรียนของตนเองเท่านั้น ไม่สามารถเข้าถึงข้อมูลของครูท่านอื่นได้
3. **การแสดงผล & กรองข้อมูล:**
   - เลือกภาคเรียน / ปีการศึกษา
   - ดรอปดาวน์วิชาและห้องเรียนจะกรองมาเฉพาะรายวิชาที่ครูท่านนั้นมีตารางสอน
   - กำหนดช่วงวันที่ต้องการตรวจสอบ
   - การ์ดสรุปยอด: จำนวนคาบทั้งหมด, เช็คแล้ว, ยังไม่เช็ค, และร้อยละการเช็คสอน (%)
4. **พิมพ์รายงานทางการ (A4 Landscape):**
   - มีเทมเพลตสำหรับพิมพ์กระดาษ A4 แนวนอน พร้อมหัวเอกสารทางการและช่องลงชื่อครูผู้สอนและหัวหน้างานพัฒนาหลักสูตรฯ
5. **ดาวน์โหลดเป็นไฟล์ Excel (.xlsx):**
   - สามารถกดปุ่มโหลด Excel ออกมาเป็นไฟล์ตารางจัดรูปแบบสวยงามพร้อมใช้งานทันที

---

### วิธีการเปิดใช้งาน

1. ดับเบิ้ลคลิกไฟล์ `start-server.bat` เพื่อเปิดเซิร์ฟเวอร์
2. เปิดเว็บบราวเซอร์ (Chrome, Edge, Safari ฯลฯ) ไปที่:
   ```
   http://localhost:3000
   ```
   *(หรือใช้ IP ของเครื่องคอมพิวเตอร์นี้เพื่อให้ครูในวง LAN เดียวกันเปิดผ่านมือถือ/แท็บเล็ตได้ เช่น `http://192.168.x.x:3000`)*
3. เข้าสู่ระบบด้วยชื่อผู้ใช้งานและรหัสผ่านของครูผู้สอน
